# ACIT4160 - Final Project - Group 12

# Project Overview

This repository contains solutions for the ACIT 4610, Final Group Project tasks.

Each folder contains a README and the corresponding notebook for the solution:
1. One dimensional bin packing - Solved with Ant Colony Optimization
2. Particle Swarm Optimization applied to 4 continuous functions
3. Multidimensional knapsack problem - Solved with Bees Algorithm
4. Spam Detection in SMS messages - Solved with Negative Selection Algorithm
5. Reinforcement learning - Implemented with Frozenlake-v1 environments
